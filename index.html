04 — SELF-HOST

روی سی‌پنل خودت
راه بندازش

کل پروژه متن‌باز و رایگانه. با این راهنمای تصویری، در کمتر از ۱۵ دقیقه نسخه‌ی خودت رو داشته باش — بدون سرور اختصاصی و بدون هزینه اضافه.

⭐ گیت‌هاب پروژه (ستاره یادت نره) ⬇️ دانلود سورس ZIP
۱

وارد سی‌پنل شو و MySQL® Databases رو باز کن

از داشبورد سی‌پنل، بخش Databases، روی MySQL® Databases کلیک کن. اینجا هم دیتابیس می‌سازیم هم کاربرش رو.

۲

یک دیتابیس بساز

در فیلد New Database یک نام مثل tempmail بنویس و Create Database رو بزن. نام کامل معمولاً با پسوند کاربری هاستت ساخته می‌شه، مثل user_tempmail — همین نام کامل رو یادداشت کن.

۳

کاربر دیتابیس + دسترسی کامل

پایین‌تر در همان صفحه، یک MySQL User با رمز قوی بساز، بعد در بخش Add User To Database کاربر را به دیتابیس وصل کن و در صفحه‌ی بعد ALL PRIVILEGES را تیک بزن.

۴

سورس پروژه رو دانلود کن

از گیت‌هاب پروژه، دکمه‌ی سبز Code → Download ZIP رو بزن (یا با گیت کلون کن). فایل ZIP رو سیستم‌ات باز کن.

۵

File Manager → پوشه‌ی ساب‌دامین

در سی‌پنل File Manager رو باز کن. اگر ساب‌دامین نداری، اول از بخش Subdomains یکی بساز (مثل temp.yoursite.com)، بعد همه‌ی محتویات پوشه‌ی سورس را در پوشه‌ی آن ساب‌دامین (معمولاً public_html/temp) آپلود کن — Extract یادت نره.

۶

ساختار نهایی باید این شکلی باشه

یعنی فایل index.html و پوشه‌های api ، includes ، cron ، pipe مستقیم داخل پوشه‌ی ساب‌دامین باشن. پوشه‌های storage و state خودکار ساخته می‌شن.

۷

فایل کانفیگ رو بساز

در پوشه‌ی includes یک کپی از config.sample.php با نام config.php بساز و بازش کن برای ویرایش.

۸

مقادیر رو پر کن

مشخصات دیتابیس (همون user_tempmail و رمزش)، دامنه‌ی ایمیلت، و مشخصات ادمین seed. همه‌ی ثابت‌ها کامنت فارسی دارند.

۹

setup.php رو یک‌بار باز کن و حذفش کن

آدرس https://temp.yoursite.com/setup.php رو در مرورگر باز کن — جداول دیتابیس و اکانت ادمین seed ساخته می‌شه. بعد از پیام موفقیت، همین فایل رو از File Manager حذف کن (امنیت!).

۱۰

یک ایمیل catch-all بساز

در سی‌پنل بخش Email Accounts → Create، روی همون دامنه‌ی ایمیل یک صندوق بساز (مثل tempmail@yoursite.com) و رمزش رو در کانفیگ یادداشت کن.

۱۱

Default Address رو تنظیم کن

در بخش Default Address گزینه‌ی Forward to Email Address را انتخاب و آدرس همون صندوق catch-all را وارد کن. حالا هر ایمیلی به هر نامی روی دامنه‌ات برسه، می‌ره تو اون صندوق.

۱۲

MX رکورد دامنه

اگر دامنه‌ات روی همین هاست میل می‌خوره، MX خودکار تنظیمه. اگر ایمیل دامنه‌ات جای دیگه‌ست، در Zone Editor رکورد MX دامنه را به هاست فعلی برگردان تا ایمیل‌ها برسند.

۱۳

Cron Jobs رو باز کن

از سی‌پنل بخش Advanced → Cron Jobs. چهار کرون زیر را با دکمه‌ی Add New Cron Job اضافه کن (مسیر پوشه‌ی خودت را جایگزین کن).

۱۴

این چهار کرون رو اضافه کن

* * * * *  php -q /home/USER/temp/cron/imap_poll.php
* * * * *  php -q /home/USER/temp/cron/process_scheduled.php
0 0,6,12,18 * * *  php -q /home/USER/temp/cron/reset_cycle.php
30 3 * * *  php -q /home/USER/temp/cron/purge_inactive.php
اولی هر دقیقه ایمیل‌ها را از IMAP برمی‌دارد، دومی ارسال‌های زمان‌بندی‌شده را می‌فرستد، سومی هر ۶ ساعت همه‌چیز را پاک می‌کند و آخری اکانت‌های ۱۰ روز بی‌استفاده را حذف می‌کند.

۱۵

تمومه! 🎉

با اکانت ادمین seed وارد شو، از پنل ادمین رمزت رو عوض کن، سهمیه‌ها رو سلیقه‌ای کن و لذت ببر. اگر جایی گیر کردی، در گیت‌هاب Issue بزن یا به تلگرام پشتیبانی پیام بده.
