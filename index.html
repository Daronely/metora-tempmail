04 — SELF-HOST

Run it on your own
cPanel — in ~20 minutes

The whole project is free and open source. Follow the visual guide below — a database, a catch-all mailbox and four cron jobs are all it takes.

⭐ GitHub repo (star it!) ⬇️ Download source ZIP

From the cPanel dashboard, under Databases, open MySQLÂ® Databases. We create the database and its user here.

Create a database

In New Database type a name like tempmail and hit Create Database. The full name usually gets your hosting username prefix, like user_tempmail â note that full name down.

3

Database user + full privileges

Further down the same page, create a MySQL User with a strong password, then in Add User To Database connect the user to the database and tick ALL PRIVILEGES on the next screen.

4

Download the source

On the GitHub repo click the green Code button â Download ZIP (or git clone). Extract the ZIP on your machine.

5

File Manager â subdomain folder

Open File Manager in cPanel. If you have no subdomain yet, create one first under Subdomains (like temp.yoursite.com), then upload the source into that subdomain’s folder (usually public_html/temp) â don’t forget Extract.

6

The final structure looks like this

That means index.html and the api, includes, cron, pipe folders sit directly inside the subdomain folder. storage and state are created automatically.

7

Create the config file

In the includes folder make a copy of config.sample.php named config.php and open it for editing.

8

Fill in the values

Database credentials (the user_tempmail name and its password), your mail domain, and the seed admin details. Every constant has an inline comment.

9

Open setup.php once, then delete it

Open https://temp.yoursite.com/setup.php in the browser â the database tables and the seed admin account are created. After the success message, delete this file from File Manager (security!).

10

Create a catch-all mailbox

In cPanel Email Accounts â Create, make a mailbox on your mail domain (like tempmail@yoursite.com) and note its password for the config.

11

Set the Default Address

In Default Address choose Forward to Email Address and enter that catch-all mailbox. Now any mail to any name on your domain flows into that one mailbox.

12

Domain MX record

If your domain already receives mail on this host, MX is already set. If its email lives elsewhere, point the domain’s MX record in Zone Editor back to this host so the mail arrives.

13

Open Cron Jobs

In cPanel go to Advanced â Cron Jobs. Add the four jobs below with Add New Cron Job (replace the folder path with your own).

14

Add these four cron jobs

The first pulls mail over IMAP every minute, the second sends scheduled mail, the third wipes everything every 6 hours, and the last purges inactive accounts at night.
